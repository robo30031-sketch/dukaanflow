# BahiPilot

> **Every Sale. Every Stock. Every Rupee.**

BahiPilot is a modern shop management application designed specifically for Indian retailers and kirana store owners. It provides an all-in-one platform to manage inventory, record point-of-sale (POS) transactions, track operating expenses, maintain customer credit (Udhar Khata), and understand overall business performance.

---

## 🌟 Key Features

- **⚡ Fast POS Billing**: Rapid product search, custom quantity & price adjustments, instant invoice generation, and support for Cash, UPI, and Udhar (Credit) sales.
- **📦 Inventory & Stock Control**: Real-time stock tracking, cost vs. selling price management, low-stock alerts, and an automated stock movement ledger.
- **📒 Digital Udhar Khata**: Customer credit balance tracking, transaction history, and seamless payment collection records (Jama).
- **📊 Financial Analytics & Reports**: Live gross profit calculation, Cost of Goods Sold (COGS), operating expense tracking, estimated net profit, and CSV exports.
- **🇮🇳 Multi-Language Support**: Complete accessibility across all 22 official languages of India (8th Schedule of the Indian Constitution).
- **🌓 Dark & Light Modes**: Optimized interface for both bright shop counters and night shifts with custom themes.
- **🔒 Enterprise Security**: Strict store-owner validation with PostgreSQL Row-Level Security (RLS) policies.

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
